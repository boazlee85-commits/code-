My App Windows Installer Return Codes

Technical Documentation for Installation Status Codes

Overview: This page documents the return codes used by the My App Windows EXE installer. These codes are returned by the NSIS-based installer to indicate the installation status or any errors that occurred during the installation process.

Return codes can be used by deployment systems, batch scripts, or other automation tools to determine whether the installation succeeded or failed, and to take appropriate action based on the result.

Installer Return Codes

Status Return Code Description
Installation Successful 0 The application installed successfully with no errors.
Installation Cancelled by User 1 The user cancelled the installation process before it could complete.
Application Already Exists Not used/documented Custom handling for existing installations is not defined in the standard installer configuration.
Installation Already in Progress Not used/documented The installer does not define a specific return code for concurrent installation attempts.
Disk Space is Full Not used/documented Disk space checks are performed by NSIS, but no custom return code is defined for this condition.
Reboot Required Not used/documented System reboot requirements are handled by NSIS, but no custom return code is defined.
Network Failure Not used/documented No network-dependent operations are configured in the standard installer.
Package Rejected During Installation Not used/documented Package validation is not configured as a separate installation step.
Miscellaneous/Custom Installer Codes Not used/documented No additional custom return codes are currently defined for this installer.

Additional Return Codes

Standard NSIS Codes: This installer uses the Nullsoft Scriptable Install System (NSIS) framework with the electron-builder default configuration. The standard NSIS installer returns codes 0 (success) and 1 (cancelled). Any other return codes would indicate system-level errors or require custom NSIS scripting.

Generic Errors: If the installer encounters any errors not covered above, the system may return error codes from the operating system or NSIS framework. Refer to the system event logs for detailed error information in such cases.

Using Return Codes in Scripts

Example (Windows Batch):

MyApp-Installer.exe
if %errorlevel% equ 0 (
    echo Installation successful
) else if %errorlevel% equ 1 (
    echo Installation cancelled by user
) else (
    echo Installation failed with code %errorlevel%
)

Example (PowerShell):

&. 'C:\path\to\MyApp-Installer.exe'
$exitCode = $LASTEXITCODE
Write-Host "Installer exit code: $exitCode"
